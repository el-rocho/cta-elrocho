# Actualización a 1.7.0

La versión `1.7.0` alinea el número de versión con las ediciones cliente y servidor y **no cambia ningún comportamiento visible**: el trabajo de este ciclo (saneamiento de nombres de copia en el servidor, token de sesión obligatorio y limpieza de código) afecta a las otras dos ediciones. Esta aplicación sigue funcionando sin servidor.

Puede instalarse sobre `1.6.1` sin desinstalarla: el identificador y la firma no han cambiado. Aun así, conserva una copia JSON independiente antes de actualizar, como en cualquier cambio de versión.

## Resumen de cambios

- Limpieza interna de utilidades y constantes sin uso. No hay cambios en pantallas, cálculos, informes ni copias.
- Número de versión `1.7.0`, coherente con el resto del ecosistema.

## Comprobar

Tras abrir la nueva versión, revisa el historial, la configuración y **Datos e informes** para confirmar que todo sigue en su sitio.
